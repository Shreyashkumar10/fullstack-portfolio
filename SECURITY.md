# Security Policy

## Supported Versions

The following table outlines the versions of this project currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | ✅ Yes              |
| 5.0.x   | ❌ No               |
| 4.0.x   | ✅ Yes              |
| < 4.0   | ❌ No               |

We strongly encourage users to upgrade to a supported version to ensure the latest security updates and patches.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this project, we want to hear from you.

Please report it by emailing us at **security@example.com** or by submitting a report through our [security disclosure form](https://example.com/security-disclosure).

### What to include in your report:

- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Any relevant logs, screenshots, or proof-of-concept code.
- The impact or potential risk of the issue.

### What to expect:

- You will receive an acknowledgment within **3 business days**.
- We will investigate and validate the issue, and may contact you for further information.
- If confirmed, we will work to address the vulnerability within **30 days**, depending on severity.
- Once resolved, we will credit you (if desired) in the release notes and/or security advisory.

> ⚠️ Please do **not** disclose the vulnerability publicly until we have had a chance to address it.
